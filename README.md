# 🧠 Clasificación de Imágenes: Pájaro vs Mariposa

Proyecto académico desarrollado en **Google Colab** para el curso *Fundamentos de Análisis y Cálculo Numérico* (Universidad del Valle).

El objetivo fue **entrenar una red neuronal feedforward** que distinguiera entre imágenes de pájaros y mariposas, aplicando los fundamentos teóricos de cálculo y análisis numérico.

> ⚠️ Por restricción del proyecto, **no se permitió el uso de redes convolucionales (CNN)**.  
> El enfoque se centró en redes neuronales multicapa (perceptrones) y el estudio de su comportamiento matemático.
